# BlogBundle

Module blog pour AkyosCMS : articles, catégories, tags, documents et options d’affichage. Intégré au CMS (SEO, builder, champs perso).

## Compatibilité

- PHP >= 8.4
- Symfony ^8.0

## Dépendances Akyos

- `akyos/core-bundle` ^8.0
- `akyos/cms-bundle` ^8.0
- `akyos/builder-bundle` ^8.0

## Installation

```bash
composer require akyos/blog-bundle:^8.0
```
